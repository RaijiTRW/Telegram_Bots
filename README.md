# 🤖 Telegram Bots - AI Админ Панель

Админ панель для управления Telegram каналами с AI-генерацией контента.

## 🚀 Быстрый Старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка Supabase

1. Создайте проект на [supabase.com](https://supabase.com)
2. Скопируйте `.env.example` в `.env.local`:
```bash
cp .env.example .env.local
```

3. Заполните переменные окружения в `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://xxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key
SUPABASE_SERVICE_ROLE_KEY=ваш_service_role_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### 3. Создание таблиц в Supabase

1. Откройте `SQL Editor` в вашем Supabase проекте
2. Скопируйте содержимое файла [supabase/migrations/001_initial_schema.sql](supabase/migrations/001_initial_schema.sql)
3. Выполните SQL запрос

### 4. Создание первого пользователя

```bash
npm run create-user
```

Выберите опцию **3** "Сгенерировать URL с токеном", скопируйте ссылку.

### 5. Запуск приложения

```bash
npm run dev
```

Откройте скопированную ссылку с токеном в браузере.

## 📚 Основные Возможности

### ✅ Реализовано

- 🔐 **Аутентификация** - вход через инвайт-токен + email/пароль
- 📝 **История постов** - просмотр всех постов с фильтрацией

- 💬 **AI модалка** - выделение текста для AI-инструкций (заглушка)
- 🎨 **Темная тема** - современный темный интерфейс
- 🛠️ **CLI управление** - создание пользователей и токенов

### 🚧 В Разработке (заглушки)

- 🤖 AI генерация постов
- 📡 Парсинг источников
- 📤 Публикация в Telegram
- ✨ AI редактирование выделенного текста

## 🗂️ Структура Проекта

```
/app
  /auth/login      # Страница логина
  /dashboard       # История постов
  /editor/[postId] # Редактор постов
  /api             # API endpoints

/components
  /ui              # UI компоненты (Button, Input, Card и т.д.)
  /layout          # Header, Layout

/lib
  /supabase        # Supabase клиенты
  /utils           # Утилиты (даты, текст)

/scripts           # CLI приложение
/supabase          # SQL миграции
/styles            # Глобальные стили
```

## 🔒 Безопасность

- HTTP-only куки для сессий
- Хеширование паролей через bcrypt
- Middleware защита всех роутов
- Row Level Security в Supabase
- Инвайт-токены с временем жизни

---

## 🛠️ Технологии

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS 4
- **Editor**: Tiptap 2.27
- **Backend**: Supabase (PostgreSQL)
- **Auth**: Custom (bcrypt + cookies)
- **Utils**: date-fns, clsx, nanoid

## 📝 Использование

### Создание пользователя

```bash

```

1. Выберите "3" - Сгенерировать URL с токеном

3. **Клик на пост** - открытие редактора
4. **Редактор** - редактирование, сохранение, публикация
5. **Выделение текста** - появление AI модалки (заглушка)
